---
title: Species Sheets
description: Template and examples for nursery species documentation.
---

Each species in the nursery should have a sheet with the following information.

## Template

| Field | Description |
|-------|-------------|
| **Common name** | Local name(s) |
| **Latin name** | Botanical classification |
| **Layer** | Canopy / understory / shrub / ground cover |
| **Soil preference** | pH, drainage, moisture |
| **Sun exposure** | Full sun / partial shade / full shade |
| **Uses** | Food, timber, medicinal, pollinator support |
| **Propagation** | Seed, cutting, division |
| **Notes** | Special care, companions, spacing |

## Example: Hazel (*Corylus avellana*)

| Field | Value |
|-------|-------|
| **Common name** | Hazel, Noisetier |
| **Latin name** | *Corylus avellana* |
| **Layer** | Shrub / small tree |
| **Soil preference** | Well-drained, pH 6–8 |
| **Sun exposure** | Full sun to partial shade |
| **Uses** | Nuts, coppice wood, wildlife habitat |
| **Propagation** | Seed, layering |
| **Notes** | Excellent coppice species. Plant in groups for pollination. |
