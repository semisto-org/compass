## Workflow

1. **Brief** — Understand the need and constraints
2. **Research** — Look at references, gather input
3. **Draft** — Create initial concepts
4. **Review** — Share with stakeholders for feedback
5. **Refine** — Iterate based on feedback
6. **Deliver** — Export final assets and document

## Tools we use

- **Figma** — UI/UX design and prototyping
- **Canva** — Quick visuals and social content
- **Illustrator** — Vector illustrations and print

## File naming convention

```
semisto-[project]-[type]-[version].[ext]
```

Example: `semisto-compass-banner-v2.png`
