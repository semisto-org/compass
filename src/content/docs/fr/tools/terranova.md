Terranova is Semisto's land management platform. It tracks parcels, plantings, and monitoring data.

## Getting access

Contact the admin team to get your Terranova account set up.

## Key features

- **Parcel management** — View and edit parcel information
- **Planting records** — Log what was planted, when, and where
- **Monitoring** — Track growth, health, and interventions

## Tips

- Always log field activities the same day
- Use the mobile interface when on-site
- Tag photos with the parcel reference
