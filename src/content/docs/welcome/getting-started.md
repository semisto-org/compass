## Finding information

Use the **sidebar** to navigate sections or the **search** (top of page) to jump to any topic.

## Contributing

Compass lives in the [semisto-org/compass](https://github.com/semisto-org/compass) repository. To add or edit content:

1. Clone the repo
2. Edit Markdown files in `src/content/docs/`
3. Open a pull request — it will be reviewed and merged

## Content guidelines

- Write in clear, simple language
- Use headings and lists for scannability
- Include practical examples when possible
- Keep pages focused on one topic
