# Compass 🧭

**The Semisto Field Guide** — internal documentation for the Semisto team.

Built with [Astro Starlight](https://starlight.astro.build/).

## Development

```bash
npm install
npm run dev
```

## Structure

| Section | Description |
|---------|-------------|
| 🏠 Welcome | Introduction and getting started |
| 🛠️ Tools | Software guides (Terranova, Slack, workflows) |
| 🌿 Field Work | Planting, monitoring, harvesting protocols |
| 🎓 Academy | Training organisation and checklists |
| 🎨 Design Studio | Design process and deliverables |
| 🌱 Nursery | Species sheets, calendars, propagation |
| 📊 Admin | ASBL obligations, accounting, templates |
| 📡 Communication | Brand guidelines, tone, editorial calendar |

## Deployment

Automatically deployed to GitHub Pages on push to `main`.

## Contributing

Edit Markdown files in `src/content/docs/` and open a pull request.
